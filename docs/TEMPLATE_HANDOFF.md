# Template Handoff Procedure

Use this procedure for every workshop-driven recipient handoff.

1. Collect the structured brand brief and approved assets.
2. Run a dry run and review the planned changes with the operator.
3. Apply the brief only after production assets are complete.
4. Run the verification gates from `README.md`.
5. Export a clean recipient directory and initialize a new repository with a single recipient-owned initial commit.
6. Record the generated handoff report, asset hashes, checklist, and verification output in the PR or internal handoff tracker.

Never hand off `.data`, `.env*`, `.next`, `node_modules`, uploads, screenshots, transcripts, exports, credentials, provider IDs, analytics IDs, or canonical repository history.
