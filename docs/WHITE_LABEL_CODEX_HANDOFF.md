# Codex Handoff Notes

Preserve the existing Mission Control product behavior while keeping the repository a net-new artifact for each recipient.

## Keep

- Dashboard, Action Board, CRM, activity, and settings workflows.
- Typed brand and module config.
- Server-side auth middleware and permission checks.
- Strict scanner and bootstrap reports.

## Replace Per Recipient

- Company/product names, app copy, metadata, PWA manifest, package name, and repository slug.
- Seed records when the recipient confirms what is safe to store.
- Brand assets and semantic tokens from the approved brief.
- Optional module configuration and connector status.

## Do Not Add

- Real credentials, tokens, private endpoints, infrastructure IDs, exports, screenshots, recordings, transcripts, customer lists, or local runtime data.
